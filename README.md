# Brouwerij Vopop: drankenkaart

Cantus-proeverij van de oudleiding van Chiro Popov. Elk chiroliedje is gekoppeld aan een bestaand Belgisch bier; de prijs is de bladzijde in het zangboekje.

- `index.html`: de online drankenkaart (scan de QR-code en "bestel" je liedjes), live op https://darkoboesmans.github.io/cantus/
- `print.html`: A4-versie om af te drukken, `menu.pdf` is de export daarvan
- `menu.js`: alle bieren, liedjes en prijzen op één plaats. Pas hier iets aan en beide versies volgen.

Tafelnummer tonen: `https://darkoboesmans.github.io/cantus/?tafel=3`
